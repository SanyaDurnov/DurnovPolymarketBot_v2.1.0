# 📊 Стратегии торговли

В боте доступны две стратегии управления позициями:

## 🎯 Стандартная стратегия (`default`)

**Файл:** `trading/position_manager.py`

**Особенности:**
- ✅ Работает вместе с **auto_entry** системой
- ✅ Автоматический вход за **1 минуту** до старта рынка
- ✅ Постепенная покупка с усреднением цены (2 итерации по 20 сек)
- ✅ Агрессивное **хеджирование** с противоположными позициями
- ✅ Дополнительные входы при снижении цены на **15%**
- ✅ Гарантированная прибыль через хеджирование

**Логика:**
1. Auto-entry входит в рынок за минуту до старта
2. Position Manager следит за позицией
3. При выполнении условий входит в противоположную сторону (хедж)
4. При падении цены усиливает исходную позицию

**Подходит для:**
- Активной торговли
- Автоматизации входов
- Хеджирования рисков

---

## 🌙 Soft Trading стратегия (`soft_trading`)

**Файл:** `trading/position_manager_soft_trading.py`

**Особенности:**
- ✅ Работает **БЕЗ auto_entry** системы
- ✅ Ручной или выборочный вход в рынки
- ✅ Более консервативные условия входа
- ✅ Гибкие параметры управления рисками
- ✅ Стабильная прибыль с меньшими рисками

**Логика:**
1. Мониторинг edge для UP и DOWN каждую секунду
2. Если edge_UP > 5% → купить UP (улучшает среднюю цену)
3. Если edge_DOWN > 5% → купить DOWN (улучшает среднюю цену)
4. Цель: avg_UP + avg_DOWN < $1.00 (гарантированная прибыль!)
5. Расчет безопасной суммы с учетом риска (max 5% от позиции)

**Математика:**
```
В Polymarket: UP + DOWN = $1.00
Если купить обе стороны со средней ценой < $1.00 → прибыль независимо от исхода!

Пример:
  avg_UP = $0.48, avg_DOWN = $0.49
  Сумма = $0.97 < $1.00
  → Прибыль $0.03 на каждый $1 инвестиций (3%)
```

**Подходит для:**
- Арбитражной торговли
- Снижения риска через хеджирование
- Стабильной прибыли без прогнозирования направления

## 🔧 Как переключить стратегию

### Способ 1: Через config.py

Откройте файл `app/config.py` и измените:

```python
# Выберите стратегию:
TRADING_STRATEGY = "default"        # Стандартная
# или
TRADING_STRATEGY = "soft_trading"   # Soft Trading
```

### Способ 2: Через .env файл

Добавьте в файл `.env`:

```bash
TRADING_STRATEGY=soft_trading
```

Или для стандартной:

```bash
TRADING_STRATEGY=default
```

## 🛠 Кастомизация Soft Trading

Чтобы изменить логику soft trading стратегии:

1. Откройте `trading/position_manager_soft_trading.py`
2. Найдите методы:
   - `_check_opposite_entry()` - вход в противоположную сторону
   - `_check_additional_entry()` - дополнительный вход
   - `_update_probabilities()` - расчет вероятностей
3. Измените логику под свои нужды
4. Добавьте новые параметры в `app/config.py` если нужно

**Пример изменений:**
- Изменить пороги входа (MATH_PROB_FOR_OPPOSITE, PRICE_ENTRY_FOR_OPPOSITE)
- Добавить новые условия (например, на основе индикаторов)
- Изменить логику расчета сумм (PositionCalculator)
- Добавить стоп-лоссы или тейк-профиты

## 🎓 Сравнение стратегий

| Параметр | Default | Soft Trading |
|----------|---------|--------------|
| Запуск | По расписанию за N мин | По расписанию за N мин |
| Выбор рынков | MarketPreSelector | MarketPreSelector |
| Начальный вход | Постепенная покупка | Нет (только мониторинг) |
| Автоматизация | Высокая | Высокая |
| Агрессивность | Средняя | Настраиваемая |
| Риск | Средний | Контролируемый |
| Хеджирование | Одна сторона + opposite | Обе стороны арбитраж |
| Управление | Автоматическое | Автоматическое |
